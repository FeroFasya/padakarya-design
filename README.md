# Padakarya Design — Official Portfolio Website

> Architectural Design & Build for Tropical Villas and Residences in Bali.

[![Vue 3](https://img.shields.io/badge/Vue-3.5-42b883?style=flat&logo=vuedotjs&logoColor=white)](https://vuejs.org/)
[![Vite](https://img.shields.io/badge/Vite-6.x-646CFF?style=flat&logo=vite&logoColor=white)](https://vitejs.dev/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.4-38B2AC?style=flat&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)

A modern, responsive landing page and portfolio showcase designed for **Padakarya Design** (Putu Upadana) and **Padakarya Construction**. Crafted with a focus on warm tropical minimalism, high-performance interactions, and seamless direct inquiries.

---

## 🌿 Key Features

- **Full-Screen Tropical Hero**: Atmospheric hero section showcasing tropical villa aesthetics with smooth rise animations.
- **Horizontal Scroll Project Showcase**: Interactive slider with drag-to-scroll, touch swipe gestures, and scroll-snap navigation for architectural project cards.
- **Interactive Workflow Stages**: Tab-based preview showing stages from *Concept*, *Drawings*, *Site*, *Interior*, *Photo*, to *Animation*.
- **Integrated Inquiry & WhatsApp**: Instant WhatsApp pre-filled contact form and persistent quick-action floating trigger.
- **Optimized Performance**: Built with Vite and Vue 3 for sub-second load times and production-ready Netlify deployment.

---

## 🛠️ Tech Stack

- **Framework**: [Vue 3](https://vuejs.org/) (Composition API, `<script setup>`)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Typography**: Newsreader (Display Serif) & Instrument Sans (Body)
- **Deployment**: Netlify

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/FeroFasya/padakarya-design.git

# Navigate to project directory
cd padakarya-design

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
```
The compiled production assets will be generated in the `dist/` directory.
